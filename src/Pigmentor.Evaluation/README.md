# Pigmentor.Evaluation

Evaluation for the **Pigmentor** RAG stack — the companion library to
*Production-Grade RAG with C# and .NET*.

Offline and online quality measurement: retrieval metrics, groundedness/faithfulness
judges, and ground-truth scoring used to track answer quality and catch regressions
before they ship.

## Install

```bash
dotnet add package Pigmentor.Evaluation
```
