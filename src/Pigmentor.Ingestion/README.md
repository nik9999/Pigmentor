# Pigmentor.Ingestion

Document ingestion for the **Pigmentor** RAG stack — the companion library to
*Production-Grade RAG with C# and .NET*.

Turns raw documents into embedded chunks ready for indexing: document loaders,
chunkers (recursive, semantic, code-aware via Roslyn, PDF via PdfPig), and the
embedding pipeline that attaches vectors and metadata.

## Install

```bash
dotnet add package Pigmentor.Ingestion
```
